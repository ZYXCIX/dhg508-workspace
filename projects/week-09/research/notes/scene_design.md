# 像素对话场景 · 设计说明

> 文件：`code/dialogue_scene.html`
> 目标：把史料库里的「孔子见老子」变成一个能看、能听的短场景，同时让每句话的来源可查。

## 1. 场景与年代

- **地点**：周守藏室。《史记》说老子是「周守藏室之史」，孔子「适周，将问礼于老子」。场景设在守藏室内，有竹简架、低案、席、铜灯、窗。
- **时间**：拟构于孔子适周问礼，约公元前六世纪末。《史记》没有明记年份，所以页面不标具体公元，只写「约」。
- **年龄**：孔子约三十余岁（《史记·孔子世家》的叙事顺序推算）；老子年岁史无明文。东汉《老子铭》说二百余岁，属于神化，不采用。
- **孔子身高**：《史记》说他「长九尺六寸」，所以像素人物比老子略高一点，但不夸张。

## 2. 服饰与陈设

| 项目 | 设计 | 依据／说明 |
|---|---|---|
| 孔子冠 | 章甫冠，黑色方冠，前有短檐 | 《礼记·儒行》：「长居宋，冠章甫之冠」 |
| 孔子服 | 深蓝灰玄端深衣，交领右衽，红褐缘边，束大带，前垂蔽膝，佩玉 | 士人玄端/深衣的简化表现；颜色为低彩度天然染 |
| 老子冠 | 玄冠，较低，两侧有垂带 | 周史官冠制的拟构 |
| 老子服 | 赭褐深衣，深色缘边，束大带，佩玉，白色长须 | 年老史官的形象；年岁不写实 |
| 剪裁 | 交领右衽、宽袖、大带、蔽膝、佩玉 | 据先秦礼制文献与通行复原设计；像素化简化，不是出土实物复原 |
| 坐姿 | 席地而坐，两膝前置，中缝分开 | 先秦室内起居方式 |
| 竹简 | 木架上的简册、地上的简堆 | 守藏室的职能 |
| 灯 | 铜灯，火苗跳动 | 形制为拟构，页面已注明 |
| 窗 | 木格窗，光柱与尘埃 | 营造室内空气感，非考古复原 |

术语说明：今天说的「汉服」是传统衣冠的统称；本片按春秋晚期（孔子、老子时代）的深衣／玄端设计，不把汉代以后才定型的冠服套用到春秋人物身上。

## 3. 对话结构

全片约六分钟，分五段（编号按当前 `LINES` 数组，0 起）：

1. **见面与寒暄**（0–25）：路上不好走、车轴断了、泰山下雨、湿衣裳、烤火喝水、车上带简、讲礼被赶、屋里安静、灰尘大、一个人闷不闷、问高寿、老子不答，最后用「你问礼，还是问我」把话头收回正题。这一段先让两人像人一样说话，不急着讲道理。
2. **礼**（26–37）：礼是给活人还是死人用的；《史记》「其人与骨皆已朽矣，独其言在耳」；「赶路」与「到家」的比喻。
3. **仁与累**（38–51）：孔子讲「克己复礼为仁」，老子追问「克的是谁的己」；孔子说「累，可总得有人爱」。中间插入喝水、「少来这套」的生活化停顿，再转到「天之道损有余而补不足」与「规矩能救人，也能杀人」。
4. **道与水**（52–64）：老子讲「上善若水」，孔子讲「人往高处走」「那也不能不走」；老子批评「把仁举在头上，像击鼓而求亡子」，再说「道不可献」；孔子问「那先生为何还著书」。
5. **龙与留宿**（65–78）：孔子说「其犹龙乎」，老子说「龙在你刚才问的那句话里」；孔子说「知其不可而为之」；天黑了，老子留他住下——「打扰。可我喜欢。」最后以《史记》的送言和「其犹龙邪」的旁白作结。

## 3.5 走位与循环

- **走位**：`MOVES` 按句号绑定动作。老子在第 17 句起身走到窗边（150），第 20 句回席；第 25 句两人起身对谈（130／210），第 37 句回席；第 43 句老子走到案边（150）递水，第 46 句回席；第 52 句走到窗边（145），第 56 句回席；第 65 句孔子起身（140），第 70 句老子起身（200），第 76 句两人回席；第 78 句孔子走向门口（-20），旁白收尾。
- **走动时**：角色从坐姿切到站姿，走完再坐下；对话可以先说完，但自动推进要等走位结束。
- **镜头**：有走位的句子用 `two`／`wide`，避免特写把走动的人切出画面。
- **循环**：控制栏「循环：开」在结尾字幕后自动从头再谈；结尾「再谈一轮」按钮跳过开场，直接回到第一句。两者都不影响「重播」（含开场）。

## 3.6 自由对话（不限于固定剧本）

固定剧本用于课堂展示；「自由对话」用于探索，不把台词锁死。

- **本地即兴池**：`FREE` 数组里有 20 组对话（礼、仁、道、水、龙、天下、弟子、诗乐、死、名、学、政、朋友、留宿、雨、年龄、助葬、仁义、教）。点「自由对话」后随机抽一组；每轮老子说完，自动再抽下一组，可以一直谈下去。
- **按词换题**：在输入框里打「礼」「仁」「道」「水」「龙」等词，点「问」，会先出现「你」的提问，再让两人接一段相关的话。没有匹配词时，从全池随机抽。
- **AI 即兴**：运行 `python code/chat_server.py`，并把 `DEEPSEEK_API_KEY` 放在环境变量里。页面会先请求 `/api/health`；有 key 时走 DeepSeek，没有 key 或请求失败时自动回退到本地即兴池。
- **人物提示**：孔子重礼、仁、君子，知其不可而为之；老子重道法自然、无为、上善若水，语气简短、常反问。AI 只写两人各一句，输出 JSON，不写旁白和动作。
- **标注**：所有自由对话都标「本地即兴」或「AI 即兴 · 话题」，来源栏写明「教学拟构，不是史料」。固定剧本里的文言引文仍按原出处标。
- **退出**：点「回到剧本」回到进入自由对话前的那一句；「重播」则从头开始固定剧本。

## 4. 哪些是史料，哪些是创作

- **文言引文**：每句在页面的「本句」栏标出来源。主要取自《史记》卷63、卷47，《庄子》天道／天运／知北游，《论语》八佾／颜渊／里仁／宪问，《老子》第七十七、八章，《诗经·小雅·小旻》，《孔子家语·观周》。
- **创作部分**：问候、行程、反问、动作、心理独白，以及「龙不在天上，龙在你刚才问的那句话里」「规矩能救人，也能杀人」等句子，都是教学拟构。页面用「拟构」标签和来源栏明确区分。
- **时代错置**：老子著书五千言事见《史记》，在出关时；剧中移作守藏室对话，属创作。页面在注里说明。
- **电影参照**：电影《孔子》（2010，胡玫导演，周润发饰孔子；又名《孔子：决战春秋》）以「知其不可而为之」概括孔子。本片借用这种沉静而倔强的语气，不直接引用电影台词。
- **文学参照**：《论语》的师生问答、《庄子》的寓言对话、《诗经》的句子，提供语气与意象。

## 5. 技术栈

- **单文件 HTML**：无外部依赖，双击即可打开，也可以嵌入 Reslides 的 `<iframe>`。
- **可选后端**：`code/chat_server.py`（Python 标准库）提供静态文件和 `/api/chat` 代理；DeepSeek key 只在服务器端，HTML 不保存 key。没有后端时用本地即兴池。
- **Canvas 320×180**：先在低分辨率画布上绘制，再以 `image-rendering: pixelated` 放大到 640×360，得到 Minecraft 式像素块。
- **程序化像素画**：人物、竹简、窗、灯、墙都用 `fillRect` 画，不用图片；方便改色、改动作。
- **动画**：`requestAnimationFrame` 驱动呼吸、眨眼、说话口型、起身／行走／坐下、火焰、尘埃、镜头推拉；对话文字用 HTML 覆盖层，保证清晰可读。
- **交互**：点击／空格下一句，`P` 暂停，`S` 字幕开关，`L` 循环，`F` 自由对话，`H` 史料面板，`R` 重播。
- **预览参数**：`?skip=1` 跳过开场；`?skip=1&still=1&line=9` 静态定格；`?end=1` 直接看结尾。

## 6. 限制

- 不是考古复原：服色、冠式、灯具形制都有拟构成分。
- 老子的年岁、相貌没有可靠记载；白须老者是后世形象，不是当时写实。
- 部分台词为思想史的综合，不是同一次对话的实录。
- 像素风格会牺牲细节；人物比例是 Minecraft 式的，不是人体比例。
- 需要核对纸本原文与《老子铭》拓片后，再定稿引用。
