# 中国长城数据库 · 检索技能（skill）

## 运行

```bash
python3 server.py          # 启动后端；然后打开 http://localhost:8000
```

- 记载检索列表：**http://localhost:8000/**
- 地图（长城走向 / 关隘 / 政区图·地形图）：**http://localhost:8000/map.html**
- 依赖：仅 Python 标准库 + `sqlite3`（数据来自 `greatwall.db`），无需额外安装。
- Windows 上若无 `python3` 命令，改用 `python server.py` 或 `py server.py`。
- 换地址/端口：`python3 server.py 0.0.0.0 8080`（默认 `127.0.0.1 8000`）。

## 一、唯一数据源

本应用**只有一个**数据源：项目目录下的 `greatwall.db`（SQLite）。

| 表 | 内容 |
|---|---|
| `records(id, volume, section, line, category, text)` | **79 条**《明史》长城记载（核心） |
| `terms(term)` / `record_terms(record_id, term)` | 用词（边墙/墙/边垣/塞垣/长城/大墙） |
| `meta(key, value)` | source / topic / criteria / generated / count |
| `geo_layers` / `geo_features` / `geo_rasters` | 地图：中国省界、明长城走向、长城关隘、地形晕渲 |

- 后端：`server.py` → `/api/meta`、`/api/stats`、`/api/records`、`/api/geo/*`
- 前端：`index.html`（记载检索列表）、`map.html`（地图）
- ⚠️ 库内文本是**简体中文**（如「正统元年」而非「正統元年」），检索请用简体。

## 二、硬性规则（必须遵守）

1. **只用库内记载。** 一切关于长城的史实只能来自 `records.text`。
   **禁止**使用数据库以外的任何来源：网页、模型记忆、其他数据集、`明史.txt` 的其它段落。
2. **库内没有就直说。** 检索无命中时回答「**库中没有相关记载**」，绝不编造人物、年代、地段或长度。
3. **必须给出史料出处。** 每条结论都要附：《明史》·**卷次**·**部类**（本纪/志/列传）· 记录号 `MZ-xxx`（源文件第 `line` 行）。
4. **纪年必须换算公元。** 出现皇帝纪年（弘治元年、嘉靖二十二年…）一律换算为公元年，换算**只查本文件第五节的附表**，不得臆造；原文未标年代时，写「该条未标注年代」。
5. **不得臆造名称。** 长城/关隘名只能取自 `records.text` 中出现的地名（山海关、居庸、嘉峪关、花马池、紫城砦、榆林、宣府、大同、兰州、松山…），或 `geo_features` 中 `layer='passes'` 的关隘名。
6. 白话文介绍要用 **AI 自己的语言复述库内记载**，不得加入库外史实。

## 三、能力 1：检索长城 / 关隘名称

**触发**：用户给出长城名、关隘名或相关地名（例：山海关、居庸、嘉峪关、花马池、榆林、宁夏边墙…）。

**步骤**

1. 在 `records.text` 中模糊检索该名称：
   `GET /api/records?q=<名称>&page_size=100`（或 SQL `text LIKE '%名称%'`）。
2. 逐条查看 `category`（修筑 / 损毁 / 战事 / 议论 / 方略 / 关隘 …）与 `text`。
3. 按下列结构输出：

```
【名称】<检索词>

【白话文介绍】<用 AI 自己的话，概述命中的每条记载；只说库内的内容>

【建造 / 相关年代】
  · <原文纪年> = <公元年>          ← 见第五节换算表
  · 原文未标年代的条目：该条未标注年代

【史料出处】
  · 《明史》卷X·<本纪/志/列传>（MZ-xxx，第 N 行）
```

**示例（山海关，检索词「山海关」）**

```
【名称】山海关

【白话文介绍】据库内记载，明廷曾以山海关为起点两次修筑长城：其一，巡抚辽东时
「筑边墙自山海关迄开原叆阳堡，凡千余里」；其二，巡抚顺天时「建议增筑塞垣，
自山海关西北至密云古北口、黄花镇直抵居庸，延亘千余里，缮复城堡二百七十所」。
（均为库内原文的白话转述，未添加库外内容。）

【建造 / 相关年代】
  · 第一条：原文作「弘治初」→ 弘治始于 1488 年（未精确到某年）
  · 第二条：原文作「十一年」，未含年号 → 该条未标注年代

【史料出处】
  · 《明史》卷一百八十六·列传（MZ-032，第 24672 行）
  · 《明史》卷一百八十七·列传（MZ-033，第 24769 行）
```

> 提示：若某名称在 `geo_features(layer='passes')` 中存在（如「山海关 Shanhaiguan」），
> 可一并说明「该关隘位于地图上的位置」，但**介绍文字仍只能来自 records**。

## 四、能力 2：按公元年份 / 皇帝年号检索

**触发**：用户给出公元年份（如 1488）或年号（如「弘治元年」「弘治」「成化九年」）。

**步骤**

1. 年号 ⇄ 公元：查第五节附表（公元 = 该年号起始年 + 年号第 N 年 − 1，元年 = 第 1 年）。
2. 在 `records.text` 中检索「<年号><年>」或年号，例：
   - `GET /api/records?q=成化九年`
   - SQL：`SELECT id,volume,section,line,category,text FROM records WHERE text LIKE '%成化九年%'`
3. 筛出与**修筑**相关的记载：`category IN ('修筑','地理建置')`，或文本含 筑 / 修 / 塞垣 / 边墙 / 边垣 / 增筑 等。
   （注意：部分修筑类记载被归入「地理建置」，如 MZ-008「……成化九年筑……」）
4. 输出**当年建造 / 修缮的长城地段名称**（取原文地名），并附出处与一句白话文：

```
【年份】公元 1473 年（明·成化九年）

【该年修筑的长城】
  · 榆林卫边墙 —— 自清水营至花马池，长一千七百七十余里（东起清水营接山西偏头关，
    西抵定边营接宁夏花马池）
  · 出处：《明史》卷四十二·志（MZ-008，第 7667 行）

（若该年还有损毁、战事等记载，可另列「同年其它记载」，标明类别。）
```

**示例（正统元年 = 1436 年）**

```
· 塞垣（拟修）—— 给事中朱纯请修塞垣；总兵官谭广言「自龙门至独石及黑峪口
  五百五十余里，工作甚难」，主张增筑烟墩防守，朝廷采纳米增筑赤城等堡烟墩。
· 出处：《明史》卷九十一·志（MZ-013，第 15069 行）
```

## 五、明代纪年 → 公元换算表

| 年号 | 皇帝 | 公元起 | 公元止 |
|---|---|---|---|
| 洪武 | 太祖 | 1368 | 1398 |
| 建文 | 惠帝 | 1399 | 1402 |
| 永乐 | 成祖 | 1403 | 1424 |
| 洪熙 | 仁宗 | 1425 | 1425 |
| 宣德 | 宣宗 | 1426 | 1435 |
| 正统 | 英宗 | 1436 | 1449 |
| 景泰 | 代宗 | 1450 | 1457 |
| 天顺 | 英宗 | 1457 | 1464 |
| 成化 | 宪宗 | 1465 | 1487 |
| 弘治 | 孝宗 | 1488 | 1505 |
| 正德 | 武宗 | 1506 | 1521 |
| 嘉靖 | 世宗 | 1522 | 1566 |
| 隆庆 | 穆宗 | 1567 | 1572 |
| 万历 | 神宗 | 1573 | 1620 |
| 泰昌 | 光宗 | 1620 | 1620 |
| 天启 | 熹宗 | 1621 | 1627 |
| 崇祯 | 思宗 | 1628 | 1644 |

**换算规则**：公元年 = 该年号起始年 + （年号年份 − 1）。
例：弘治元年 → 1488；成化九年 → 1465 + 8 = **1473**；嘉靖二十二年 → 1522 + 21 = **1543**。

> 说明：本表是**技能自带**的固定换算工具，不属于「库外长城资料」；除此之外不得引入库外信息。

## 六、禁止事项

- ❌ 引入库外长城史实（长度、起止点、修建者、战役细节等）——只能复述 `records.text`。
- ❌ 把「库中没有」说成「历史上没有」；应表述为「**库中没有该内容的记载**」。
- ❌ 杜撰或修改年代；凭记忆写公元年（必须查第五节的表）。
- ❌ 用非库内名称指代长城地段。

## 七、接口速查

| 用途 | 调用 |
|---|---|
| 元信息（来源/备注/收录标准） | `GET /api/meta` |
| 统计（总数、按类别/部分/用词） | `GET /api/stats` |
| 全文检索 | `GET /api/records?q=<关键词>&page_size=100` |
| 按用词筛选 | `GET /api/records?term=边墙` |
| 按类别筛选 | `GET /api/records?category=修筑` |
| 按部类筛选 | `GET /api/records?section=志` |
| 地图图层 | `GET /api/geo/layers`、`/api/geo/<layer>`、`/api/geo/raster/terrain` |

SQL 直查示例：

```sql
-- 某年修筑的长城
SELECT id, volume, section, line, text
FROM records
WHERE text LIKE '%成化九年%' AND category = '修筑';

-- 含某关隘名的全部记载
SELECT id, volume, section, line, category, text
FROM records WHERE text LIKE '%花马池%';
```
